# toprakkars.github.io

My personal portfolio site — live at **https://toprakkars.github.io**

Built with plain HTML, CSS and JavaScript (no framework), hosted on GitHub Pages.

## Features

- Responsive single-page layout (about, projects, skills, contact)
- English / German language switch, remembered between visits
- Dark theme with a single accent colour

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
